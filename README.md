# Portfolio Showcase

A polished personal portfolio website for showcasing software projects, technical skills, and professional background.

## Features

- Modern single-page portfolio layout
- Project cards with repo and demo links
- Skills section
- About section
- Contact call-to-action
- Responsive design for desktop and mobile

## Why this matters

This final project turns your technical work into a professional presentation, making it easier to share with recruiters, clients, and collaborators.

## Run locally

```bash
python -m http.server 8000
```

Then open:

```text
http://localhost:8000
```
